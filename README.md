# Quick Symbols Landing

Interactive landing page for **Quick Symbols**, a Chrome extension that lets you quickly search, copy and use special characters.

## Live website

https://quick-symbols-web.vercel.app/

## About

The landing page is an interactive experience built around the idea of “fishing” for symbols.

Click a symbol to catch and copy it. After exploring the page, users can discover and install the full Quick Symbols Chrome extension.

## Tech stack

- TypeScript
- Vite
- CSS
- Vercel

## Local development

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm typecheck
pnpm build
```

Production files are generated in `dist/`.

## Quick Symbols

Quick Symbols is a lightweight Chrome extension for finding and copying special characters without interrupting your workflow.
